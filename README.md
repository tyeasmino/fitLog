# FitLog

FitLog is a dark, responsive workout management web application that helps users explore workouts, build a daily workout plan, and save workouts for later.

## 🚀 Live Demo

[Live Demo](https://fitlog-nu-jade.vercel.app/)

## 📌 Features

- Browse a complete workout library with workout details, categories, equipment, duration, calories, and ratings.
- View detailed workout information including difficulty, sets, reps, instructions, and workout statistics.
- Add workouts to Today's Plan and track the number of planned exercises.
- Save workouts for later and manage saved workouts from the My Plan page.
- Sort planned and saved workouts by Duration, Calories, or Rating.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- React Toastify
- Context API
- REST API

## 📂 Main Pages

- `/` — Home page with workout banner and workout library
- `/workouts/[id]` — Workout details page
- `/my-plans` — Today's Plan and Saved workouts
